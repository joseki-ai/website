Innovations

Innovations

What sets the platform apart: computation at GPU scale, from order book simulation to model training and search, and confidential computing for customer code and data.

Core

Computation at GPU scale

Simulation, feature computation, training and search run on GPUs rather than on CPU cores. A GPU executes tens of thousands of threads over high-bandwidth memory, so independent work, such as parameter sets, markets, instruments and environments, runs concurrently instead of in sequence, and its Tensor Cores execute the matrix arithmetic of modern models in mixed precision. For a research team the effect is iteration speed: more hypotheses tested and stress-tested per day, on capacity that grows with the GPUs rather than with a cluster to administer.

  • Throughput over clock speed. A CPU core is fast at one task; a GPU is fast at thousands of the same task. Parameter sweeps, scenario sets, feature computation across instruments and reinforcement-learning environments are that kind of work.
  • Tensor Cores for modern models. Transformers, state-space models and large recurrent networks are dominated by matrix multiply-accumulate, which Tensor Cores execute in mixed precision (TF32, BF16, FP8) at a throughput CPUs do not approach.
  • No host round trips. Order book replay, model state and environment steps stay on the card in high-bandwidth memory; nothing is copied back to the host per event.
  • Scale without rewriting. The same code runs on one GPU or across many with data parallelism, and is certified against a CPU reference engine.

Simulation

GPU-native simulation

Order book replay, matching, fills and accounting run as CUDA kernels, with many independent simulations per GPU. A CPU reference engine certifies that both engines produce the same sequence of events.

Privacy

Confidential computing

Customer code and data run on confidential GPUs inside a hardware-isolated enclave: CPU memory encrypted by the processor, GPU memory in a protected region, and encrypted transfers between them. Keys are released only after remote attestation of the enclave. Nobody outside it can read the code or the data: not other tenants, not Joseki staff, not the root user of the host.

  • NVIDIA Confidential Computing
  • AMD SEV-SNP
  • Intel TDX
  • remote attestation
  • encrypted CPU–GPU transfers
  • customer-held keys

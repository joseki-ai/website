Products · Feature Engineering

Feature engineering

A library of market features and option analytics, user-defined features and learned features, computed point-in-time on captured market data and shared between research, backtesting and live use.

Request early access →
Library

Feature library

Standard features computed from trades, quotes and order book data at any sampling clock.

returns

Returns and momentum

Log returns, momentum and mean-reversion statistics over configurable horizons.

volatility

Volatility

Realized, Parkinson, Garman–Klass and EWMA estimators, with intraday seasonality.

microstructure

Microstructure

Order flow imbalance, microprice, quoted and effective spread, depth and queue imbalance.

volume

Volume

VWAP deviation, volume profile, trade intensity and participation rate.

cross-sectional

Cross-sectional

Rolling beta, correlation, lead–lag, spreads and ratios between instruments.

calendar

Calendar

Session phase, time to expiration and scheduled event windows.

Option analytics

Implied volatility solved per quote, volatility surfaces fitted per snapshot under butterfly and calendar no-arbitrage constraints, and Greeks to third order for vanilla and digital options.

  • vanna

  • charm
  • speed
  • color
  • implied volatility per quote
  • SVI surface fits
  • skew and term structure
  • digital-option Greeks
Custom

User-defined features

Features are defined as expressions or code against the same inputs as the library. Sampling clock, window and normalization are parameters of the definition, so one definition produces the same values in research, backtests and live use.

  • time, tick, volume and dollar bars
  • rolling and expanding windows
  • z-score
  • rank transform
  • winsorization
  • sector and beta neutralization
  • EWMA smoothing
Learned

Learned features

Sequence encoders trained on raw or engineered inputs produce embeddings that are used as features alongside the library.

  • temporal convolutions
  • recurrent networks
  • attention
  • state-space models
  • autoencoders
  • self-supervised pretraining
Analysis

Feature analysis

Predictive power, decay, stability and redundancy are measured before a feature is used in a strategy.

  • information coefficient
  • IC decay by horizon
  • permutation importance
  • SHAP values
  • regime stability
  • correlation clustering
  • leakage tests
Correctness

Point-in-time computation

Inputs are presented in the order they would have reached the strategy: receive time plus the configured transport latency. A feature whose window is incomplete is marked invalid rather than forward-filled.

  • No look-ahead. No feature reads data after its own timestamp.
  • No training-serving skew. One implementation for research, backtests and the live stack.
  • Pinned definitions. Each backtest records the feature definition versions it used.

Platform

Shared conventions across products

All products use the same record formats, symbology, timestamps and dataset versions.

  • One definition. A feature computed in research is the same feature in a backtest and in live use.
  • Point-in-time data. Reference data, features and simulations use information as it was available at the time.
  • Reproducible runs. Each run records the dataset versions, configuration and build it used.
  • GPU scale. Simulation, feature computation, training and search run on GPUs, so independent work runs concurrently and the same code scales from one GPU to many.
  • one record format across venues
  • nanosecond timestamps
  • versioned datasets
  • point-in-time reference data
  • GPU acceleration
  • confidential computing

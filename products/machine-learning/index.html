Products · Machine Learning & RL

Machine learning and reinforcement learning

Managed GPU infrastructure for training, hyperparameter search and reinforcement learning on market data, with point-in-time datasets, environments built on the market simulator and reproducible runs.

Request early access →
Infrastructure

Datasets, compute and reproducibility

Data preparation, GPU provisioning and run tracking are provided.

datasets

Point-in-time datasets

Features and labels materialized from versioned market data, with purged and embargoed splits.

compute

Managed GPUs

GPU instances with pinned drivers, CUDA and frameworks, and multi-GPU training.

runs

Reproducible runs

Each run is pinned to its dataset versions, code, seed and environment.

Supervised

Supervised learning

Predictive models trained on market labels, with validation methods suited to overlapping and autocorrelated samples.

  • PyTorch
  • JAX
  • gradient-boosted trees
  • MLPs
  • temporal convolutions
  • recurrent networks
  • transformers
  • state-space models
  • purged k-fold cross-validation
  • embargo
  • walk-forward analysis
  • label design
  • sample weighting
  • distributed data-parallel training
  • mixed precision
Reinforcement learning

Reinforcement learning environments

Vectorized GPU environments built on the market simulator, with queue position, latency and transaction costs in the loop. The replayed market does not react to the agent's orders; queue position is estimated from the back of the level, and market impact is a configurable model.

  • on-policy (PPO)
  • off-policy (SAC, DQN variants)
  • offline (CQL, IQL)
  • multi-agent settings
  • reward shaping
  • inventory and risk penalties
  • curriculum over regimes
  • domain randomization
Search

Hyperparameter and strategy parameter search

Model hyperparameters and strategy parameters are searched against simulated results in parallel on GPUs, with out-of-sample scoring.

  • Bayesian optimization
  • evolution strategies (CMA-ES)
  • population-based training
  • multi-objective search
  • walk-forward analysis
Deployment

Experiment tracking and deployment

Experiments are tracked with full lineage, models are registered by version, and trained models export to standard inference formats.

  • experiment tracking
  • model registry
  • lineage
  • ONNX export
  • TensorRT inference
  • SDK for custom models
